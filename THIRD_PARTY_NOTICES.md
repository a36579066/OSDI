## Raspberry Pi 3 Model B+ Device Tree Blob

`kernel/bcm2710-rpi-3-b-plus.dtb` is the Device Tree Blob used by the QEMU Raspberry Pi 3B+ run target. Its corresponding Device Tree source is maintained in the Raspberry Pi Linux tree at [`arch/arm/boot/dts/broadcom/bcm2710-rpi-3-b-plus.dts`](https://github.com/raspberrypi/linux/blob/rpi-6.12.y/arch/arm/boot/dts/broadcom/bcm2710-rpi-3-b-plus.dts).
